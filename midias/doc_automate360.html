6. Motor n8n (Passo a Passo)

Fila de envio automatizada com inteligência anti-spam:

  1. Trigger: Cron a cada 10 min.
  2. Filtro: Leads pending + next_send_at <= NOW() + Limite do Plano.
  3. Horário Comercial: Disparo apenas entre 08:00 e 18:00.
  4. Random Delay: Nó Wait com expressão JS: 
    const tempos = [120, 300, 480, 720]; 
return tempos[Math.floor(Math.random() * tempos.length)];
  5. Envio SMTP: Dados dinâmicos da tabela smtp_credentials.
  6. Limite: Máximo de 20 e-mails por hora/conta.

7. Script SQL Supabase

CREATE TABLE profiles (
  id UUID REFERENCES auth.users PRIMARY KEY,
  plan_type TEXT DEFAULT 'basic',
  emails_sent_this_month INTEGER DEFAULT 0,
  payment_status TEXT DEFAULT 'active'
);

CREATE TABLE smtp_credentials (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES profiles(id),
  smtp_host TEXT, smtp_port INTEGER,
  smtp_user TEXT, smtp_pass TEXT -- AES-256
);

CREATE TABLE leads (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES profiles(id),
  email TEXT NOT NULL,
  status TEXT DEFAULT 'pending' CHECK (status IN ('pending', 'sent', 'follow_up_1', 'follow_up_2', 'follow_up_3', 'follow_up_4', 'follow_up_5', 'replied', 'paused')),
  next_send_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
